# Gymple hardware — demostración visual

**[Abrí index.html](index.html)** o descargá [la versión offline](descargas/gymple-demo-v04.zip). Tres vistas: numpadPCfrontal y portillo, componentes y tutorial de armado. Sin instalación, compilación ni dependencias remotas.
